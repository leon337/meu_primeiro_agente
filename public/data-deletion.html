Instruções para Exclusão de Dados

Hello Agent · última atualização: 3 de agosto de 2026

O Hello Agent não mantém atualmente um banco de dados durável de conversas. O histórico ativo fica temporariamente em memória e é removido quando a sessão é reiniciada, expira ou a instância do servidor é encerrada.

Solicitar exclusão

  1. Envie um e-mail para predixaibr@gmail.com com o assunto Exclusão de dados — Hello Agent.
  2. Informe somente o canal usado e os dados mínimos necessários para localizar a solicitação. Não envie senhas, tokens ou documentos sensíveis.
  3. Após confirmar legitimamente a solicitação, removeremos os dados sob nosso controle e responderemos com a conclusão ou com a justificativa legal aplicável.

Dados mantidos por terceiros

Mensagens e registros processados por Meta/WhatsApp, Google, Vercel ou Tailscale estão sujeitos aos procedimentos e prazos desses fornecedores. Quando necessário, indicaremos o canal oficial apropriado.

Apagar a conversa da PWA

Na interface web, abra as configurações e escolha Nova conversa. Isso encerra a sessão atual do Hello Agent e cria um novo identificador local.
